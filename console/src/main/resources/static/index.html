Queue가 정할 숫자는 Core에 1초에 들여보낼 새 예매 사용자 수 하나입니다. 아래 순서대로 진행하면 단계마다 판정과 다음 할 일을 이 패널이 알려 줍니다. 설정 채우기는 아래 실행 폼만 채우고 부하는 보내지 않습니다. 실행은 폼의 실행 버튼으로 직접 합니다. 방법과 이유의 원본은 ticket-core docs/core-capacity.md입니다.
